# anyforms

Делаем силиконовые формы (молды) — от мастер-модели и оснастки до готовой формы. Более 5 лет в производстве форм: для мастеров свечей, гипса и мыла, для ресторанов и кондитеров. Вокруг производства — магазин готовых форм, 3D-печать и обучение.

🌐 **Сайт:** [anyforms.ru](https://anyforms.ru)

## Что можно посмотреть

|---|---|---|
| Формы под заказ | [anyforms.ru](https://anyforms.ru/) | Присылаете идею, фото или эскиз — считаем, делаем 3D-модель, печатаем оснастку и отливаем форму |
| Магазин готовых форм | [anyforms.ru/shop](https://anyforms.ru/shop) | Каталог, корзина и онлайн-оплата, доставка СДЭК по всей России |
| 3D-печать | [anyforms.ru/3d-print](https://anyforms.ru/3d-print) | Корпуса, гибкие детали, мелкие серии — без минимального заказа |
